      <h3>🏰 dungeonMath</h3>
      <p>
        Es un juego <b>plataformero</b> y <b>educativo / puzzle matemático</b>.
        Recibes una operación matemática y tu objetivo es saltar hasta el cofre
        con la opción correcta. Son 10 niveles, y tu objetivo es hacerlos sin
        equivocarte; si te equivocas no ganas ni pierdes nada, pero si aciertas
        sumas un punto. Fue creado con HTML + CSS + JS y corre todo en un solo
        archivo <code>.html</code>.
      </p>

      <h4>🎮 Controles</h4>
      <p>
        Para moverte a la izquierda y derecha usa <kbd>←</kbd> <kbd>→</kbd> o
        <kbd>A</kbd> <kbd>D</kbd>, y para saltar <kbd>↑</kbd> o <kbd>Espacio</kbd>.
      </p>
